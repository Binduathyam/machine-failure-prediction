# Predictive Maintenance Project

## Project Summary

Predictive Maintenance is a process used to predict machine failures before they happen. This project analyzes machine sensor data to understand equipment condition and identify patterns related to machine failure.

The main purpose of this project is to explore the dataset, understand machine behavior using data analysis, and prepare the data for future machine learning model development.

This project uses a predictive maintenance dataset containing machine operational values such as temperature, torque, rotational speed, and tool wear.

---

## Problem Statement

In industries, unexpected machine failures can lead to production delays, higher maintenance costs, and reduced efficiency.

This project helps analyze machine sensor data to understand when a machine may fail, allowing maintenance teams to take preventive actions before breakdown occurs.

---

## Project Objective

The objectives of this project are:

* To understand and analyze predictive maintenance data
* To inspect machine operational parameters
* To identify patterns in machine failure data
* To perform Exploratory Data Analysis (EDA)
* To visualize important machine features using graphs
* To prepare the dataset for future machine learning implementation

---

## Dataset Information

**Dataset Name:** Predictive Maintenance Dataset

**File Used:** `predictive_maintenance.csv`

The dataset contains machine-related operational data and failure information.

### Features Available in Dataset

| Feature                 | Description                                     |
| ----------------------- | ----------------------------------------------- |
| Type                    | Machine category/type                           |
| Air temperature [K]     | Temperature of surrounding air in Kelvin        |
| Process temperature [K] | Temperature during machine processing           |
| Rotational speed [rpm]  | Speed of machine rotation                       |
| Torque [Nm]             | Rotational force generated by machine           |
| Tool wear [min]         | Tool usage duration in minutes                  |
| Target                  | Failure indicator (0 = No Failure, 1 = Failure) |

## What is EDA?

EDA (Exploratory Data Analysis) is the process of understanding the dataset before building a machine learning model.

In EDA, we:

* Understand dataset structure
* Check missing values
* Find patterns in data
* Create graphs for better understanding

This helps improve decision making during model development.
